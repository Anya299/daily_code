# 70-Day Software Engineering Interview Prep

> A structured 70-day intensive roadmap for becoming interview-ready for software engineering, AI/ML, and product-based company roles.

## 🎯 Objective

This repository documents my 70-day preparation journey covering:

- Python
- Data Structures & Algorithms
- Problem Solving
- SQL & DBMS
- Object-Oriented Programming
- Operating Systems
- Computer Networks
- Software Development
- Git & GitHub
- APIs & Backend Development
- System Design
- AI/ML
- Generative AI
- Projects
- Resume & Interview Preparation

The goal is not just to complete topics, but to build the ability to **understand, implement, debug, explain, and solve problems independently**.
